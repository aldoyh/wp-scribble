Cannot connect to development server
The desktop app couldn't connect to the local development server. Make sure the backend and frontend servers are running.

To start the development servers:

  1. Open terminal and navigate to the project directory
  2. Run npm run develop_backend in one terminal
  3. Run npm run develop_frontend in another terminal
  4. Wait for both servers to start, then click "Retry Connection"
